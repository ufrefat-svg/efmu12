# EF Mu 12 · Web-Apps

Apps zur Fachseminarsitzung „Einsatz digitaler Medien im Musikunterricht“,
Staatliches Studienseminar für Lehrerausbildung, Regionalstelle Mittelthüringen (Erfurt), Fachseminar Musik.

- `index.html`: Startseite mit allen Apps
- `maestro-rush.html`: Maestro Rush (Anpfiff der Sitzung)
- `musikomat.html`: Musik’o’mat (Tisch 4)
- `rhythmus-tresor.html`: Rhythmus-Tresor (Tisch 5)
- `kompetenz-fussball.html`: Kompetenz Fußball (Abpfiff)
- `fonts/`: lokale Schriften, keine Verbindung zu Google

Die Apps laufen im Browser ohne Anmeldung und senden keine Eingaben an einen Server.
